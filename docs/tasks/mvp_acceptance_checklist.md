# MVP Acceptance Checklist

実装完了前にすべて確認する。

## プロダクト

- [ ] ホームで難易度（初級 / 中級 / 上級）と制限時間（30秒 / 1分 / 2分）を選べる
- [ ] 開始するとスレッド / DM 風のプレイ画面になる（サイドバーなし、吹き出し、フローティング HUD）
- [ ] 相手メッセージに対し、指定返信をローマ字で打つ。ふりがなが見える
- [ ] 不正解キーではカーソルが進まない。打ち切ると自動送信され、年収が加算される
- [ ] 時間切れで結果画面。年収が主役。速度・正確性・ミス数・最大連続も出る
- [ ] 分析画面で苦手キー / 指 / 動きが見える。データ不足時は空枠ではなく不足の旨を出す
- [ ] ホーム ⇄ 分析、結果 → 再プレイ / ホーム / 分析 の導線がある

## ルール

- [ ] IME 変換は使わない。ローマ字と、返信に含まれる英数字・記号を打つ
- [ ] `shi`/`si` など仕様のゆれを受け付ける
- [ ] 獲得額 = 基本給 × 速度係数 × 正確性係数。年収は成立した通の合計
- [ ] 途中の返信は 0 円。キーイベントをプレイ中に API へ送らない
- [ ] 初回アクセスで匿名 ID をブラウザに保存し、同じブラウザの履歴を識別する
- [ ] 個人情報・ログインは無い

## データと環境

- [ ] 各難易度 12 本以上の問題が D1 に入る
- [ ] 問題は世界観どおりで、URL 級の長記号列を含まない
- [ ] プレイ結果はゲーム終了時にまとめて D1 へ保存する
- [ ] D1 変更は migration。ローカルと本番が分かれている
- [ ] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [ ] `just check` で lint、typecheck、test、build が通る
- [ ] React と Hono が 1 つの Worker にデプロイされている
- [ ] 公開 GitHub リポジトリ `Takumi-0408/typing-app` の main に載っている
- [ ] Cloudflare Workers 上でプレイできる
