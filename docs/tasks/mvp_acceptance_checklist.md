# MVP Acceptance Checklist

実装完了前にすべて確認する。

## プロダクト

- [x] ホームで難易度（初級 / 中級 / 上級）と制限時間（30秒 / 1分 / 2分）を選べる
- [x] 開始するとスレッド / DM 風のプレイ画面になる（サイドバーなし、吹き出し、フローティング HUD）
- [x] 相手メッセージに対し、指定返信をローマ字で打つ。ふりがなが見える
- [x] 不正解キーではカーソルが進まない。打ち切ると自動送信され、年収が加算される
- [x] 時間切れで結果画面。年収が主役。速度・正確性・ミス数・最大連続も出る
- [x] 分析画面で苦手キー / 指 / 動きが見える。データ不足時は空枠ではなく不足の旨を出す
- [x] ホーム ⇄ 分析、結果 → 再プレイ / ホーム / 分析 の導線がある

## ルール

- [x] IME 変換は使わない。ローマ字と、返信に含まれる英数字・記号を打つ
- [x] `shi`/`si` など仕様のゆれを受け付ける
- [x] 獲得額 = 基本給 × 速度係数 × 正確性係数。年収は成立した通の合計
- [x] 途中の返信は 0 円。キーイベントをプレイ中に API へ送らない
- [x] 初回アクセスで匿名 ID をブラウザに保存し、同じブラウザの履歴を識別する
- [x] 個人情報・ログインは無い

## データと環境

- [x] 各難易度 12 本以上の問題が D1 に入る
- [x] 問題は世界観どおりで、URL 級の長記号列を含まない
- [x] プレイ結果はゲーム終了時にまとめて D1 へ保存する
- [x] D1 変更は migration。ローカルと本番が分かれている
- [x] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [x] `just check` で lint、typecheck、test、build が通る
- [x] React と Hono が 1 つの Worker にデプロイされている
- [x] 公開 GitHub リポジトリ `Takumi-0408/typing-app` の main に載っている
- [x] Cloudflare Workers 上でプレイできる
