年収打の見た目、どれがピンチ？

仕様どおりの 4 画面（ホーム / プレイ / 結果 / 分析）を、骨格だけ変えた 3 方向で置いてあります。 カードを開いて右上の画面切替で見てください。文言と数字は全部同じです。

PATTERN A

Slack ワークスペース

左にチャンネル、中央がタイムライン。いちばん「仕事の Slack」に近い骨格です。
PATTERN B

年収 HUD 重視

サイドは細く、年収とタイマーを常時大きく出す、ゲーム寄りのポップカードです。
PATTERN C

スレッド / DM

サイドバーなし。吹き出しとフローティング HUD で、会話に没入するカジュアル寄せです。
白ベース＋パステル、Slack 風、今どき IT 企業、という共通条件は 3 案とも同じです。 選ぶときは「仕事してる感」「スコアの見やすさ」「会話への没入」のどれを前に出したいかで見てください。
